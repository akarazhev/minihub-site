Fixes and diagnoses

Reading unfamiliar code until the mechanism is named, with line references and, where possible, a test that shows it.

MQTT delivery that stopped after a reload

When max_ack_pending was not set, a configuration reload left open MQTT sessions with a limit of zero, and QoS 1 and 2 delivery stopped. The fix and a regression test were merged less than two hours after the pull request was opened.

A watermark that stops moving

An accumulator watermark never advances when a key keeps receiving data and the function emits nothing for it. Verified with a test against the Rust core; the team revisited the design, restored the drop API in four SDKs, and merged the documentation fix in #3660.

QuantConnect/Lean#9790

A job that forgets which method it was asked to run

Odoo's queue_job recorded the __name__ of the function it found, not the name it was asked for, so a module that installs a replacement under another name, as auditlog does for write and unlink, breaks the job when it runs. The name was lost in four places; the fix and three tests are in #998.

OCA/queue#996

A PDF invoice import that drops amounts

Odoo's PDF invoice import dropped a total printed with one decimal and turned an integer into hundredths, without an error. Checked by running the conversion against the module's own test cases and sample invoice: the proposed fix changes none of them, while making the decimals optional would let a fragment of the VAT number beat any smaller total under the max rule.

OCA/edi#1423

An e-invoice check that raised the wrong error

get_level() raised IndexError instead of its own ValueError on a CustomizationID without :, as a Belgian e-fff invoice carries. Merged an hour after it was opened and released in factur-x 7.7; the library parses the invoices that Odoo's OCA import reads.
